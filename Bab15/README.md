| `06_apa_output.py` | Latihan while |
| `07_projek_v15.py` | Menu berulang |

Fail `.in` mengandungi input automatik untuk contoh yang memerlukan `input()`.

## Cara jalankan

```powershell
cd Bab15
python 01_while.py
```

Atau dari folder utama repo:

```powershell
python Bab15\01_while.py
```

## Nota

Setiap `while` mesti mempunyai update atau `break` supaya tidak menjadi infinite
loop. `else` pada `while` hanya dijalankan jika loop tamat secara normal, bukan
melalui `break`.
