# Bab 21 — Dates dan Math

Folder ini mengandungi kod untuk Bab 21 buku **Tour Guide For Python**.

## Fail

| Fail | Tujuan |
|---|---|
| `01_datetime.py` | Tarikh dan masa |
| `02_timedelta.py` | Tambah/tolak hari |
| `03_math.py` | `math` functions |
| `04_round.py` | Pembundaran |
| `05_apa_output.py` | Latihan tarikh/math |
| `06_projek_v21.py` | Laporan bertarikh |

## Cara jalankan

```powershell
cd Bab21
python 01_datetime.py
```

Atau dari folder utama repo:

```powershell
python Bab21\01_datetime.py
```

## Nota

`round()` menggunakan banker's rounding. `math.ceil` dan `math.floor` mempunyai
tujuan berbeza. Output tarikh bergantung pada masa sebenar.

Nama: Aiman Hakim
Purata: 84.67
Purata ceil: 85
Purata floor: 84
