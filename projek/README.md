# Projek — Sistem Analisis Keputusan Pelajar

Folder ini akan mengandungi aplikasi sebenar yang dibina sepanjang buku.

Setiap milestone akan ditambah mengikut bab:

| Bab | Milestone | Status |
|---:|---|---|
| 01 | Banner sistem v0.1 | Siap (contoh: `Bab01/02_sistem.py`) |
| 02 | Banner sistem v0.2 dengan comment dan `sep` | Siap (contoh: `Bab02/07_banner_v2.py`) |
| 03 | Data pelajar pertama dalam variable, banner v0.3 | Siap (contoh: `Bab03/08_banner_v3.py`) |
| 04 | Casting data pelajar daripada teks kepada nombor | Siap (contoh: `Bab04/07_projek_v4.py`) |
| 05 | Bersih dan format data pelajar, banner v0.5 | Siap (contoh: `Bab05/09_projek_v5.py`) |
| 06 | Kira jumlah, purata, peratus dan status lulus | Siap (contoh: `Bab06/11_projek_v6.py`) |
| 07 | Input pelajar dan laporan berformat | Siap (contoh: `Bab07/09_projek_v7.py`) |
| ... | ... | ... |

Buat masa ini, kod milestone awal boleh dilihat dalam folder `Bab01`.
