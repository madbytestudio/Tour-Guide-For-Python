# Projek — Sistem Analisis Keputusan Pelajar

Folder ini akan mengandungi aplikasi sebenar yang dibina sepanjang buku.

Setiap milestone akan ditambah mengikut bab:

| Bab | Milestone | Status |
|---:|---|---|
| 01 | Banner sistem v0.1 | Siap (contoh: `Bab01/02_sistem.py`) |
| 02 | Output dan comments yang lebih kemas | Akan datang |
| 03 | Simpan rekod pelajar pertama | Akan datang |
| ... | ... | ... |

Buat masa ini, kod milestone awal boleh dilihat dalam folder `Bab01`.
