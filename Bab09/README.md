## Cara jalankan

```powershell
cd Bab09
python 01_tuples.py
```

Atau dari folder utama repo:

```powershell
python Bab09\01_tuples.py
```

## Nota

Tuple immutable. Untuk mengubah item, tukar kepada list, ubah, kemudian tukar
semula kepada tuple. Tuple satu item mesti mempunyai koma: `("Aiman",)`.
