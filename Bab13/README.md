Folder ini mengandungi kod untuk Bab 13 buku **Tour Guide For Python**.

| Fail | Tujuan |

| `06_nested.py` | Nested `if` |
| `07_pass.py` | `pass` placeholder |
| `08_apa_output.py` | Latihan condition |
| `09_projek_v13.py` | Gred dan status pelajar |

## Cara jalankan

```powershell
cd Bab13
python 01_if.py
```

Atau dari folder utama repo:

```powershell
python Bab13\01_if.py
```

## Nota

Block `if` mesti diindentasi dengan 4 ruang. Semak condition yang paling
ketat dahulu dalam rantaian `elif` supaya gred tidak tersilap.
