## Cara jalankan

```powershell
cd Bab16
python 01_for_list.py
```

Atau dari folder utama repo:

```powershell
python Bab16\01_for_list.py
```

## Nota

`for` sesuai apabila bilangan item diketahui. Gunakan accumulator seperti
`jumlah = 0` sebelum loop jika perlu mengira jumlah.
