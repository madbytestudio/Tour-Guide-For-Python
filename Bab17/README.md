# Bab 17 — Functions dan Arguments

Folder ini mengandungi kod untuk Bab 17 buku **Tour Guide For Python**.

## Fail

| Fail | Tujuan |
|---|---|
| `01_function.py` | Function tanpa parameter |
| `02_arguments.py` | Satu parameter |
| `03_return.py` | `return` |
| `04_default.py` | Default parameter |
| `05_keyword.py` | Keyword arguments |
| `06_no_return.py` | `None` |
| `07_apa_output.py` | Latihan default |
| `08_projek_v17.py` | Function analisis |

## Cara jalankan

```powershell
cd Bab17
python 01_function.py
```

Atau dari folder utama repo:

```powershell
python Bab17\01_function.py
```

## Nota

`return` memulangkan nilai; `print()` hanya memaparkan. Function tanpa `return`
mengembalikan `None`. Default parameter mesti diletakkan selepas parameter biasa.
